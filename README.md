# Analisis-restaurante-sql
Analisis de datos de un restaurante usando sql

##Objetivo:
Analizar datos de un restaurante para comprender sus patrones de consumo, ingresos y comportamiento de clientes.

##Herramientas:
-SQL
-Excel (limpieza de datos)

##Dataset:
Dataset de transacciones de un restaurante con informacion sobre cuentas, propinas, dias, horarios y tamaño de grupo.

##Analisis realizados:
Las consultas SQL que se utilizaron, se encuentran en el archivo 'queries.sql'.

##Insights:
-El dia sabado concentra la mayor facturacion del restaurante.
-La cena representa la mayor parte de los ingresos totales.
-El dia viernes presenta el mayor porcentaje en propinas, aunque el domingo muetra valores cercanos, indicando un comportamiento consistente durante el fin de semana.
-A medida que aumenta el tamaño del grupo, disminuye el porcentaje de propinas.

##Conclusion:
El analisis permite identificar oportunidades para optimizar el flijo de servicio en los horarios mencionados, mejorar los ingresos en los dias y horarios con menor porcentaje de ventas y propinas y la compresion del comportamiento de los clientes.
